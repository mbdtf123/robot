## 2.6 受力扰动分析（最大倾角 10°）

```matlab
run_disturbance
```

扰动模型：`t = 2.0 s` 时对车身质心施加水平恒力 `F`，持续 50 ms，
即冲量 `J = F × 0.05 N·s`（正号 = 向前推）。模型里新增了外力项
`Q_x = F, Q_θ = −F·l·cosθ`（见 `wip_dynamics.m`）。

**结论（修复后参数）**

| 冲量区间 | 行为 |
|---|---|
| `J < 1.18 N·s`（Δv < 1.37 m/s） | 峰值倾角 < 10°，**满足要求** |
| `1.18 ~ 2.25 N·s` | 倾角会超 10° 但还能救回来 |
| `> 2.25 N·s` | 真的翻倒 |

**但有两个必须知道的问题**：

1. **速度不收敛**。扰动后机器人会一直朝一个方向滚，
   实测速度衰减时间常数 **40 s**（关掉腿防倒也才 11 s）。
   根因是速度环为纯 P 且增益太小，缺少积分项——任何恒定速度都对应一个平衡点。
   要真正停在原地，必须给速度环加积分，或启用位置环 `robot_kp`。
2. **±10° 限幅形同虚设**。`main.cpp:451` 的 `target_pitch` 限幅要触发
   需要 `|v| = 200 rad/s = 7 m/s`，而 `max_velocity` 只有 2 rad/s，
   永远不会触发。真正限制倾角的是直立环本身。

腿防倒机构还会让速度衰减**慢 4 倍**（40 s vs 11 s）：
它在稳态下把重力力矩抵消掉，机器人能在任意倾角+任意速度下"平衡"，速度环因此几乎失效。

## 2.7 位置环整定（robot_kp）

```matlab
run_position
```

扰动 J=1.0 N·s 后的三种接法对比：

| 配置 | 100 s 后位置误差 | 末速度 | 判定 |
|---|---|---|---|
| 不开位置环 | 15.0 m | 0 | 一直漂 |
| 旧接法（误差→腿部偏移） | 0.36 m | 0.47 m/s | ✗ 振荡不收 |
| **新接法（误差→目标俯仰角）** | **0.004 m** | **0.002 m/s** | **✓ 收敛** |

两个关键结论：

1. **位置环必须接在目标俯仰角上**，不能接在腿部偏移上。
   腿部偏移只移动质心、改变平衡点，不产生持续力矩，控不住位置。
2. **`6050_middle.cpp` 的 +0.6° 硬偏置必须归零**，否则产生稳态位置误差：

   ```
   稳态误差 = PITCH_BIAS_DEG / robot_kp
   ```

   实测 k=1/2/3 → 0.599 / 0.301 / 0.201 m，与 0.6/k 严格吻合。
   偏置归零后误差降到 **1.4~4.2 mm**。

**推荐参数**：`robot_kp = 2.0 deg/m`（峰值 7.93° < 10°，收敛 1.4 mm）。
`k = 3.0` 时峰值 9.93° 已贴上限，不建议再高。

**代价**：位置会来回摆约 ±3.8 m、约 60 s 才收敛（`fig14`）。
因为速度环仍是纯 P，位置环只能借它的慢通道；想更快必须给速度环加积分。

## 3. 模型结构

```
             ┌──────────── 100 Hz 控制中断 (Ts = 10 ms) ────────────┐
             │                                                      │
  pitch ──►  │  速度环: target = vel_kp·(v_meas − v_tgt)             │
  v_meas ──► │          ↓ 限幅 ±10°                                 │
  gyro  ──►  │  直立环: u = kp·(target − pitch) + kd·gyro            │
             │          ↓ 限幅 ±1.0                                  │
             └──────────┼──────────────────────────────────────────┘
                        ▼
               电机一阶 (tau_m = 12 ms)  ──►  τ_tot = 2·tau_max·u
                        ▼
        WIP 动力学 ──► [x, ẋ, θ, θ̇]      θ>0 = 后倒
                        ▼
        传感器: 俯仰 Kalman 滞后 5 ms (+0.6° 偏置) / 陀螺 2 ms / 编码器 LPF 28 ms
```

动力学方程（拉格朗日，`q = [x, θ]`）：

```
M_tot = m_b + 2 m_w + 2 J_w / R²
J_tot = m_b l² + J_b

[ M_tot        −m_b l cosθ ] [ẍ ]   [ τ/R − m_b l θ̇² sinθ            ]
[ −m_b l cosθ   J_tot      ] [θ̈ ] = [ τ  + m_b g (l sinθ − dx_cm)    ]
```

`dx_cm` 是腿部姿态造成的身体质心水平偏移（防倒机构的作用通道）。

## 6. 代码核对结论

### ✅ 原本怀疑、但**是对的**（不要改）

**1. 直立环 `balance_kd = -0.02` 的负号是对的**
控制律 `u = kp·(target − pitch) + kd·gyro` 中 `e = −θ`，
故 `kd·θ̇` 等价于标准 PID 的 `Kd·ė`，`Kd = +0.02` 为正阻尼。
**符号正确，问题在幅值**（见下）。

**2. `torque_normalization_factor = 1.0/max_torque` 恒等于 1**
`calculate_wheel_torque()` 里的"归一化"是空操作，力矩限幅在 ±1 早已由
`max_torque=1.0` 完成。无害，但注释有误导性。

### ❌ 真问题（按严重程度排序）

**P0 — `vel_kp = -0.05` 符号反了，应为 `+0.05`**

`target_pitch = vel_kp·(v_cur − v_tgt)`。速度偏快时（误差为正）需要**后倾减速**，
即 `target_pitch` 应为正；代码取负号 → 前倾 → 更快，构成正反馈。

仿真（场景 B）：轮速冲到 **4.7 m/s**、位移漂 **32 m**，即"越跑越快"。
线性化验证：`vel_kp=-0.05` 在 s=+0.21 处产生不稳定极点；改为正号后极点回到 0
（位置自由漂移，正常）。

**P0 — `set_leg_position_smooth` 阻塞 350 ms，是致命的实时性缺陷**

`main.cpp:331` 的 `vTaskDelay(duration_ms + 100)` 让整个平衡环冻结：
期间不发新力矩、不跑 `motor_update()`，电机保持最后一次占空比。

仿真：**第一次触发就跌倒，t = 0.15 s**（场景 A / C）。即使 PID 修好也救不回来。
阻塞时长扫描（`fig5`）显示：**>30 ms 就开始失稳，40 ms 直接倒**。
标准应是"发指令立即返回"，舵机自己走完 250 ms。

**P1 — `balance_kd` 幅值过大，激发 14.9 Hz 极限环**

电机越强，闭环越快。`tau_max = 0.15` 时该反馈把最快闭环极点推到
230 rad/s（36 Hz），远超 10 ms 采样能支撑的范围（Nyquist 50 Hz）。

仿真：`kd = -0.02` → **14.9 Hz 抖动，θ 峰峰值 1.4°，力矩 60% 时间饱和**
（实物表现就是高频嗡嗡抖 + 电机发烫）。降到 `-0.01` 后该模态完全消失（0.18°）。
`fig4` 给出 `(tau_max, kd)` 的稳定域，当前参数点正好落在边界上。

**P1 — 并联五连杆的 `beta` 过零导致小腿舵机脉冲阶跃 589 μs**

这是**闭链机构特有**的问题，串联腿不会有。

`Kms.c:82-83` 把 `beta` 归一化到 `[0, 2π)`：
```c
beta1 = (beta1 >= 0) ? beta1 : (beta1 + 2.0f * PI);   // 负角 -> ~+2π
```

五连杆正常工作时 `beta` 会随 `leg_x` 减小而穿过 0。一旦为负，归一化把它变成
≈359°，随后 `main.cpp:280` 的限幅 `beta_deg ∈ [-20, 80]` 把 359° **截成 80°**，
`s2 = 90 − 80 = 10`，脉冲瞬间塌下去。

实测（`fig7` / `fig8`）：

| leg_x | beta | 小腿脉冲 |
|---|---|---|
| 50 mm | 1.92° | 2022 |
| 52 mm | 0.45° | 2033 |
| **52.7 mm** | **≈0 → 359.7°** | **2033 → 1444（−589 μs）** |
| 60 mm | 354.9° | 1444 |

- 跳变等价于舵机瞬间甩约 **80°**，是直接的机械冲击源
- 触发条件：`leg_x > 52.7 mm`，即防倒逻辑在**前倾超过 6.35°** 时就会踩到
  （`leg_offset = 2 mm/°`，而 `max_leg_offset = 20 mm` 允许到 60 mm）
- 正确做法：`beta` 不要归一化到 `[0,2π)`，改为归一到 `(-π/2, 3π/2)` 或不归一化；
  按 `beta = −0.98°` 算，脉冲应为 **2043**，是平滑连续的

**P2 — 防倒逻辑触发过于灵敏**

`adjust_leg_position_for_balance` 的判据是 `|ΔX| > 0.5 mm`，而增益 2 mm/°，
即**偏 0.25° 就触发**一次舵机动作。场景 B 中 20 s 内触发 **1298 次**（65 Hz）。
配合 P0 的阻塞，等于让控制环长期停摆。建议加滞环（±3°）并限频（≤5 Hz）。

**P2 — 逆解无解时会用到未初始化内存**

`main.cpp:266` 的 `JointAngles joint_angles;` 未初始化；
`Kms.c:68` 若判别式 < 0 则**不写**输出结构体，后续 `alpha_left` 等直接用栈上垃圾值。
建议 `= {}` 初始化并在无解时返回错误码。

**P2 — 并联五连杆的两个曲柄是"各自独立"选分支的**

`Kms.c:86-94` 中 `alpha` 与 `beta` 的分支判定彼此独立。并联闭链机构的两个曲柄
必须落在**同一装配构型**上，否则会解出一组几何上互不相容的"假解"。

实测扫描（x∈[10,90], y∈[70,180]，共 8991 点）：
- 有解率 97.8%（194 点无解，属正常奇异/超行程）
- 末端还原误差**中位数 0.000 mm**
- 误差 > 2 mm 的假解仅 **2 点**，集中在右边缘 `x∈[64,88], y∈[72,96]`
- **固件实际工作区 x∈[20,60] 内最大误差 0.00 mm** → 当前用法安全

结论：现有站立/防倒范围不会踩到，但工作空间右缘存在风险。
建议加一句"两曲柄分支必须同侧"的显式判定，而不是各判各的。

**P3 — 单位混用**

`enc_get_speed()` 返回 **rad/s**，但 `main.cpp` 全按 m/s 注释、打印、限幅
（`max_velocity = 2.0` 实为 2 rad/s ≈ 0.07 m/s）。
后果：蓝牙 `speed:2.0` 实际让机器人几乎不动；`current_position` 也是 rad·s 积分。

**P3 — `current_position` 固定 dt 积分**

`current_position += current_velocity * 0.01f` 写死 10 ms，未用实际 `dt`，
且量纲仍是 rad/s。当前 `robot_kp = 0` 未启用，暂无影响。

**P3 — 位置环那行是笔误**

`main.cpp:413` `leg_position_offset += robot_kp * leg_position_offset`
应为 `robot_kp * position_error`。`robot_kp > 0` 时会变成指数放大。

**P3 — 左右舵机限幅不一致**

左侧 `s0 ∈ [0,130] / s2 ∈ [0,120]`，右侧 `s0 ∈ [0,90] / s2 ∈ [0,180]`
（`main.cpp:287-290` vs `306-309`），零位脉冲也不同（+130/-130 vs 0/-75）。
站立点实测：L = [2113, 1964]，R = [1983, 2019]，两侧不对称 130 μs 量级，
会造成机械偏斜。建议统一到对称限幅后重新标零位。

## 7. 建议的最小改动

```c
// main.cpp:56-61
static PIDParams current_pid = {
```
